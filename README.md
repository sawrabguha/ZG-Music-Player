# ZG Music Player

An offline music player for Android 13 and above, made as an unofficial fan tribute to Legend Zubeen Garg.

## Features
- Plays music stored on the phone, with background playback and notification controls
- Songs, Folders, Favourites and Playlists tabs
- Now Playing screen with swipe gestures and animations
- Equalizer with presets and bass boost
- Multiple colour themes and song sorting
- Delete songs directly from the app

## Built with
Kotlin, Jetpack Compose, Media3 (ExoPlayer)
